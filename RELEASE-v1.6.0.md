## Практика без мыши

Live предлагает связанные трёхминутные занятия для Ubuntu, Chrome, VS Code и терминала. Следующий шаг зависит от результата предыдущего. В Chrome и VS Code отрабатываются сочетания, адреса и имена файлов вручную вводить не требуется. Ошибка оставляет текущее задание, ошибочная клавиша подсвечивается красным. Подсветку можно отключить рядом с клавиатурой и руками.

Chrome и VS Code заполняют учебную область. Второстепенные панели убраны с экрана занятия. Пробел запускает и продолжает занятие, в строке печати он отображается пустым интервалом. Пауза и итог показывают четыре показателя и график в оформлении Stamina. Для Live скорость измеряется в действиях в минуту.

Крестик окна теперь позволяет сохранить подход и выйти из приложения. Отмена закрытия оставляет занятие на паузе. Alt+F4 во время активной симуляции по-прежнему закрывает только учебное окно.

Все сочетания проверяются по физическим клавишам независимо от EN/RU. В профиле MateBook D16 клавиша F11/PrtSc учитывает режим Fn. Для настоящего F11 при режиме мультимедиа требуется Fn+F11. Print не засчитывается как F11. На клавиатуре одна левая клавиша ⊞.

## Установка

Linux: распакуйте архив и запустите `install.sh`. Он обновит приложение и ярлык «Код вслепую — Linux». Нужны GTK 4 и Python с PyGObject. Для системных сочетаний в Wayland разрешите захват клавиш в диалоге GNOME.

Windows: распакуйте ZIP целиком и запустите `TouchTyping.exe`. Нужен .NET Framework 4.8 или 4.8.1. Учебные приложения работают внутри песочницы.

## Проверка

Сборки и автоматические проверки общего движка выполняются перед публикацией. Linux проверяется также в изолированном GNOME с настоящей подачей клавиш. Кнопка «Автопроверка» сохраняет отчёт и журналы отдельно от личного прогресса.

Нативный GUI и физический ввод на реальной Windows машине пока не проверены. Для такой проверки в Windows архив включены `Test-Live-UI.ps1` и тестовый runner. Физический Fn ноутбука не доступен обычным событиям приложения: проверяется итоговый код F11 или Print, полученный от системы.
