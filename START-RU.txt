Код вслепую — запуск на Windows

1. Извлеките все файлы из архива в любую папку.
2. Откройте TouchTyping.exe и выберите тренировку.

Печать. Пробел начинает набор, F4 скрывает клавиатуру, Esc показывает
результат. Рекорд сохраняется от 180 набранных символов.

Работа без мыши. F1 показывает подсказку, F8 пропускает задание,
F12 показывает результат. Окна, вкладки и файлы учебные.

Через «Свои наборы» можно создать и отредактировать список символов,
сочетаний клавиш или текст для печати.

Установщик, интернет и права администратора для запуска не нужны.
Для запуска нужен .NET Framework 4.8 или 4.8.1. На Windows 10
22H2 и Windows 11 этот компонент уже входит в систему.

Программу можно перенести на другой компьютер в архиве или целой
папкой. Личные настройки и результаты сохраняются локально.
