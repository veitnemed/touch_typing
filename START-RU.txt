Код вслепую для Windows x64

Извлеките весь архив и откройте TouchTyping.exe или Start-Live.cmd.
Live содержит четыре класса — Ubuntu, Chrome, VS Code и терминал.
Выберите класс, режим и сложность, затем нажмите пробел или F5.

Каждый подход длится три минуты. В песочнице задания продолжают
состояние учебных окон, вкладок и документов. После двадцатого задания
сразу начинается следующий блок. При ошибке исправьте текущий шаг.
F8 включает паузу, пробел продолжает её, F10 открывает результат. При конфликте клавиш
управления с заданием действующая клавиша показана на кнопке.

Итог содержит выполненные действия, ошибки, точность и рекорд.
Рекорды сохраняются для полных трёхминутных подходов отдельно
по классу, режиму и сложности.

Все горячие клавиши работают по физическим позициям в EN и RU.
Песочница моделирует Ubuntu на обеих платформах. ⊞ обозначает
Windows-клавишу. Alt+Tab переключает учебные окна, Alt+F4 закрывает
учебное окно, PrtSc открывает панель снимков. Учебный док содержит
Chrome, VS Code, терминал и файлы, которым соответствуют ⊞+1…4.
⊞+Space переключает учебную раскладку. Терминальные команды,
файлы, Git, пакеты, процессы и перезагрузка выполняются в модели.

Кнопки ⌨ и 👐 скрывают подсказки клавиатуры и рук.
Красная подсветка ошибочной клавиши отключается независимо.
В Chrome и VS Code адреса и имена файлов вручную набирать не нужно.
В профиле MateBook D16 для F11 в режиме мультимедиа нажимайте Fn+F11.
Нажатие без Fn отправляет PrtSc и не засчитывается как F11.
Alt+1 — Live, Alt+2 — печать, Alt+3 — редактор, Alt+4 — прогресс.
«Отдельное сочетание» открывает прежние упражнения.

Для старого курса Windows запустите Start-Workday.cmd. Старый
тренажёр печати доступен через TouchTyping.exe --legacy-typing.

Сборка для Windows 10/11 x64 требует .NET Framework 4.8 или 4.8.1.
Движок .NET входит в архив. Результаты сохраняются в
%LOCALAPPDATA%\TouchTypingStudio.

Автопроверка. Запустите Test-Live-UI.ps1. Параметр -FullSession
добавляет проверку полного трёхминутного подхода. Результаты и
отдельный тестовый профиль сохраняются в папке отчёта.
