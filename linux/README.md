# Код вслепую для Linux

Распакуйте архив и запустите `./install.sh`. Ярлык «Код вслепую — Linux» появится на рабочем столе и в меню приложений. Требуются Python 3, PyGObject, Cairo и GTK 4 (`python3-gi`, `python3-cairo`, `gir1.2-gtk-4.0`). Среда .NET входит в сборку. Переносимую версию можно открыть через `./touch_typing.py`.

## Live

Сначала выберите учебную систему Ubuntu или Windows 10. Она меняет системные сочетания, рабочий стол и маршруты «Рабочего дня», но не меняет настройки вашей ОС. Затем выберите класс или «Рабочий день», поручение и способ обучения — «По шагам» или «Самостоятельно». Пробел или F5 запускает подход, пробел продолжает паузу. В диалоге GNOME разрешите передачу клавиш учебному рабочему столу. Отсчёт начинается после разрешения. F8 ставит занятие на паузу, F10 открывает результат. Если задание использует эту клавишу, кнопка показывает свободную клавишу управления.

Лимит действий (20, 40, 60 или 100) и таймер (3 или 10 минут) включаются независимо. Чтобы пройти упражнение целиком, выберите «Без лимита действий» и «Без таймера». Загрузите отчёт в Chrome, перенесите его в проект, сохраните правку в VS Code и проверьте содержимое из терминала. Каждый шаг проверяет состояние рабочего места. Чтобы продолжить незаконченный маршрут со счётом и ограничениями из черновика, выберите прежние класс, уровень и способ обучения, затем «Продолжить с сохранённого места». Рекорды сравниваются при одинаковых условиях.

Рабочий стол моделирует окна, обзор, Alt+Tab, рабочие столы, размещение окон и панель снимков. Chrome содержит вкладки, адресную строку, поиск и учебные страницы. VS Code содержит нейтральный проект task-list, редактор, проводник, палитру команд и встроенный терминал. Буфер Python подсвечивается цветами GitHub Dark Default при вводе, без запущенного VS Code или интерпретатора. Сочетания проверяются по физическим клавишам в EN и RU. Личный выбор пальцев задаётся в редакторе. Подсказки клавиатуры и рук выключаются кнопками ⌨ и 👐.

В Chrome и VS Code окно приложения заполняет учебную область. Сценарии требуют сочетания клавиш, адреса и имена файлов вручную набирать не нужно. Ошибочно нажатая клавиша подсвечивается красным до исправления; эту подсветку можно отключить рядом с кнопками подсказок. Итог и пауза показывают время, количество, темп и точность над графиком. Во время занятия точность скрыта.

Профиль MateBook D16 учитывает совмещённую F11/PrtSc и одну левую ⊞. В режиме мультимедиа нажимайте Fn+F11 для полноэкранного режима. При включённом Fn Lock достаточно F11. Тренажёр различает итоговые события F11 и Print; сама Fn обычно не передаётся приложению. Режим Fn можно выбрать в подготовке занятия.

В ветке Ubuntu позиции избранных приложений и сочетание смены языка берутся из настроек GNOME. В учебной Windows 10 действуют собственные системные сочетания. Приложение вне дока можно найти через обзор по клавише ⊞. При таком переключении текст переводится в выбранную учебную раскладку. До учебного переключения используется текст, полученный от системы.

Системные действия выполняются в модели рабочего стола. Alt+F4 закрывает учебное окно, PrtSc открывает учебную панель захвата, Enter сохраняет изображение в учебной папке Pictures/Screenshots и помещает его в учебный буфер. При потере фокуса занятие и таймер приостанавливаются, захват отпускается. Для продолжения нажмите пробел и при необходимости снова разрешите передачу клавиш.

Крестик настоящего окна предлагает сохранить занятие и закрыть приложение. При отмене занятие остаётся на паузе. После паузы можно закрыть приложение и обычным Alt+F4.

## Терминал

Команды работают с учебными файлами, пакетами, процессами и Git в памяти приложения. Поддерживаются навигация, операции с файлами, просмотр и поиск текста, кавычки, шаблоны путей, перенаправления и простые конвейеры. `sudo`, `apt`, `chmod`, `chown`, управление процессами, `reboot` и `shutdown` изменяют учебную систему. Для неподдерживаемых команд и вариантов синтаксиса выводится объяснение. Tab дополняет путь по текущим учебным файлам, стрелки восстанавливают введённые команды.

## Печать и личные упражнения

Alt+1 открывает Live, Alt+2 — печать, Alt+3 — редактор, Alt+4 — прогресс. В меню ☰ есть раздел «Клавиши» для отдельных прежних упражнений. Во время печати F4 переключает клавиатуру, F7 — руки, F8 — паузу, Esc открывает результат. Доступны уроки, словари и фразы EN/RU, свои тексты, символы и Python на материале учебного проекта task-list.

Редактор принимает сочетания нажатиями и текстом. Для стороны используйте RCtrl, LShift и LSuper. Шаги разделяются через ` → `. Личные сочетания редактируются и удаляются, встроенные можно скрывать. Проверка реальной системной смены языка по физической A доступна в прежнем разделе «Клавиши».

Прогресс хранится в `$XDG_DATA_HOME/TouchTypingStudio/progress.xml`, обычно это `~/.local/share/TouchTypingStudio/progress.xml`.

## Сборка и проверки

`./linux/build-release.sh /путь/к/новой-папке` собирает linux-x64 с SDK .NET 10. `TOUCH_TYPING_RUNTIME` выбирает другую архитектуру. Регрессии запускаются через `dotnet run --project linux/tests/SharedRegression.csproj`, `dotnet run --project linux/tests/LabRegression.csproj` и `dotnet run --project linux/tests/TerminalRegression.csproj`. Проверки протокола запускаются с `PYTHONPATH=linux python3 linux/tests/test_practice.py` и отдельным проверочным профилем.

`linux/tests/test_lab_window.py` проверяет настоящее окно GTK на изолированном GNOME Wayland с именем training-qa. Флаг `--small` проверяет размер 960×600, `--timed` проходит полный трёхминутный подход. Для картинок укажите существующую папку через `TOUCH_TYPING_QA_OUTPUT`. Тест требует отдельную D-Bus-сессию тестового композитора и раскладки US/RU.

## Автопроверка

На главном экране Live кнопка «Автопроверка» запускает отдельный тестовый сеанс GNOME с полным трёхминутным занятием. Весь прогон занимает около четырёх минут. Проверяются четыре класса на US/RU, удержание модификаторов, пауза и фокус, элементы редактора, подтверждение удаления, подсказки и прежние упражнения. Сеанс использует временный профиль. Отчёт `report.json`, журналы и снимки ошибки сохраняются в папке проверок приложения, путь показан после завершения.

В переносимой сборке можно запустить `./check.sh --output /папка/отчёта`. Параметр `--timed` добавляет настоящее занятие на 180 секунд. В исходниках `--full` дополнительно запускает стресс-тесты C# и требует SDK .NET 10. `--seed 7` задаёт воспроизводимый набор заданий. Отчёт отмечает каждый прогон как passed или failed и содержит путь к журналу. Для проверки графического интерфейса нужны `gnome-shell`, `dbus-run-session` и `gsettings`.
