## Практикум Live

В Ubuntu, Chrome, VS Code и терминале теперь по 12 поручений на трёх уровнях. В каждом минимум 20 проверяемых действий. Ещё три маршрута «Рабочий день» связывают приложения общей файловой системой. Например, скачанный в браузере отчёт можно перенести в проект, изменить в редакторе и проверить его содержимое из терминала.

В Chrome Ctrl+L выделяет весь адрес. Стрелки и Shift меняют границы выделения, Ctrl+X вырезает видимый фрагмент. В редакторе Ctrl+L выделяет строку, Ctrl+X при пустом выделении вырезает текущую строку, Ctrl+Z возвращает её. Ctrl+J переключает нижнюю панель. В терминале стрелки перемещают каретку или вызывают историю, ↓ возвращает черновик. Backspace удаляет слева, Delete справа.

По умолчанию занятие идёт без таймера. Можно задать предел в 20, 40 или 60 действий либо 3 или 10 минут. «По шагам» подсказывает сочетание и пальцы. В самостоятельном режиме цель видна на экране, F1 открывает подсказку. Итог показывает активное время, выполненные действия, темп, точность и график ошибок.

Незаконченное поручение сохраняется при выходе. Выберите тот же класс, способ обучения и уровень, затем «Продолжить с сохранённого места». Рабочее место восстановится, начнётся новый отсчёт.

## Запуск

- **Ubuntu x64.** Распакуйте архив Linux и запустите `./install.sh`. Программа установки добавляет ярлык на рабочий стол. Для захвата системных сочетаний в Wayland подтвердите запрос GNOME.
- **Windows x64.** Распакуйте весь ZIP и откройте `Start-Live.cmd`. В разделе Ubuntu используется учебный профиль рабочего стола.

Файлы, буфер и приложения Live виртуальные. Снимок сохраняет учебную сцену в Pictures/Screenshots. Для физической Fn доступно только итоговое событие клавиатуры. Встроенные упражнения печати, персональные сочетания и результаты прежних занятий доступны в своих разделах.

В архиве Linux есть `check.sh` для проверки в отдельном сеансе GNOME. На Windows проверку отрисовки можно запустить командой `TouchTyping.exe --qa --check-live-render ПАПКА`. Она сохраняет кадры Chrome, VS Code и терминала.
