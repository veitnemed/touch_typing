# Что означает результат на карточке «Печать»

Карточка связывает **точность и активное время одной завершённой попытки**. Первая строка той же точности уступает более быстрому завершённому прохождению. Пауза в активное время не входит. Если время не было записано, вместо него показано «—». Отдельный старый рекорд скорости не используется для вычисления времени.

- Сравниваются основной режим, сложность, число циклов и таймер; для упражнения со смешанным вводом учитывается исходная раскладка. Прерванная конечная попытка и работа над ошибками не участвуют. Таймер в конечном занятии не превращает недопечатанный текст в рекорд. Смена текста пользовательского набора создаёт новый набор результатов, простое переименование нет.
- Точность вычисляется из количества верно выполненных действий и ошибок: `100 × верные / (верные + ошибки)`. Текстовый символ и физически выполненная команда дают по одному действию. Пороги сравниваются до округления. При отсутствии подходящей попытки цвет серый; ниже 90% красный, от 90% оранжевый, от 97,5% зелёный.
- Для старых профилей читается **завершённая** история основного режима. Если версия не записала параметры и нет сопоставимого нового рекорда, результат помечается как архивный и предлагается только при настройках по умолчанию. Сохранённый агрегат, который мог возникнуть при выходе из незаконченного упражнения, не считается подтверждением завершённой попытки. Данные исходного профиля при просмотре не изменяются.

Проверка: `linux/tests/test_typing_mode_records.py` использует штатный протокол движка. В наборе есть анонимный профиль, записанный настоящей v1.7.0: завершены 150 символов первого урока с одной ошибкой. Это проверка совместимости формата, а не измерение скорости человека.
