# Что проверяли в обычном курсе TouchTyping 1.9.0

Это реальные проходы через карточки и события клавиатуры, а не количество строк в каталоге. В тесте у пользователя ещё нет черновика. После перехода к следующему поручению исходная карточка открывает сохранённый шаг и то же число зачтённых действий.

Полный каталог и разные уровни проверяет отдельный автоматический обход; длина конкретного урока не означает, что курс исчерпан.

## Печать

Печать → обычный запуск: один конечный цикл на 350–550 символов, таймер выключен. Можно взять несколько циклов с общим счётчиком или выбрать бесконечный режим без полосы. Прогресс, лучшая точность и активное время собираются из фактического результата. Отдельно проверяются необкруглённые 90%, 97,5% и 98%, физические позиции клавиш RU/EN и повторное открытие сохранённых результатов. Исправление формируется из промахов одной попытки; его можно продолжить после перезапуска или открыть уже завершённый итог без повторного зачёта.

## Что означает стенд

- GTK/X11: реальное окно и события XTest, две карты XKB, обычный запуск, малое окно. Независимая сверка эталона использует настоящий VS Code с Jupyter и одной и той же контрольной книгой.
- WPF: реальный Windows Server и события SendInput в обычном окне. Растровые проверки 96/120/144 DPI измеряют отрисовку, но не подтверждают смену масштаба самой Windows в живом сеансе.
- Физический MateBook, клиентская Windows 10/11 и Wayland этой приёмкой не покрыты. Fn нельзя подтвердить по виртуальному столу.
