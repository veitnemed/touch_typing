# Практика на каждый день: редактор и окна

Эти короткие тренировки выбираются напрямую в соответствующем классе
каталога: три в VS Code и одна в Ubuntu. Они работают с учебными файлами
внутри приложения и не запускают внешний редактор или команды на компьютере.

| Упражнение | Проверяемый результат |
| --- | --- |
| VS Code: определение и возврат | F12 открывает импортированную функцию, а не одноимённую соседнюю; Ctrl+Alt+- в профиле Linux или Alt+← в Windows возвращает в прежний файл на ту же позицию. |
| VS Code: использования и переименование | Shift+F12 открывает связанные места; F2 → имя → Enter меняет определение, импорт и вызовы. Одноимённая локальная переменная, строка и соседний модуль остаются прежними. Esc отменяет. |
| VS Code: средняя строка | Ctrl+L захватывает среднюю строку. После Ctrl+/ знак комментария появляется только на ней. Ctrl+Z восстанавливает исходную позицию и выделение; Ctrl+Shift+K удаляет только среднюю строку, Ctrl+Z восстанавливает её. |
| Ubuntu: документация и код рядом | Super+←/→ ставят окна по половинам экрана, Super+↑ разворачивает, Super+↓ возвращает к исходной геометрии, Super+H сворачивает. Переключатель возвращает то же окно, вкладку и каретку. Повторное отдельное нажатие на занятой половине снимает привязку; удержание не вызывает серию привязок. |

Переходы и переименование предназначены для учебного Python-проекта. Это
не анализатор произвольного Python-кода. Миссия Ubuntu воспроизводит
описанные операции с окнами учебного рабочего стола на обеих платформах,
не управляя настоящими окнами пользователя.
