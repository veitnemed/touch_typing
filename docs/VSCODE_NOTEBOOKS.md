# Блокноты в курсе VS Code

Откройте **Live → VS Code → Настроить**. Блокнот не требует отдельного режима, установленного Python, Jupyter, расширений или сети. Он открывается рядом с обычным файлом через `Ctrl+P`. Занятия входят также в подбор заданий VS Code с лимитом времени/действий.

| Уровень | Занятие | Как понять, что получилось |
|---|---|---|
| Основы | Проверить расчёт из блокнота и передать результат | Прочитать заявку в `app.py`, найти блокнот, запустить данные с переходом, вычислить показатель, сохранить блокнот и записать число в отчёт. |
| Рабочие приёмы | Исправить формулу в блокноте по заявке | Увидеть, что существующий код считает минимум. Выбрать нужную операцию, изменить ячейку, заново её выполнить и передать **новый** результат. |
| Сложный | Пересчитать сводку на новых данных | Добавить запись из заявки. Изменение текста не выполняет код. После выполнения данных прежний результат вычисления помечается как предыдущий; нужны повторный расчёт и сохранение. |

Вариант выбирает материал: число выполненных задач за неделю (сумма), самая долгая доставка (максимум) или число проверок (длина списка). Ячейка, вкладка, вывод и итоговый текстовый файл принадлежат одному учебному проекту. Правильная клавиша при неверном числе не завершает сдачу.

**Клавиши в блокноте:** в режиме выбора ↑/↓ перемещаются между ячейками. Enter открывает текст, Esc возвращает к выбору. Ctrl+A в режиме редактирования выделяет текущую ячейку; работают удаление, движение курсора, отмена и учебный буфер обмена. Ctrl+Enter выполняет текущую ячейку на месте и возвращает к режиму выбора. Shift+Enter выполняет и выбирает следующую, а в конце создаёт пустую ячейку того же типа и сразу даёт в ней печатать. Ctrl+S сохраняет блокнот в учебном проекте. Назначения сверены с [документацией VS Code о Jupyter](https://code.visualstudio.com/docs/datascience/jupyter-notebooks#_running-cells), [официальной картой Jupyter](https://github.com/microsoft/vscode-jupyter-keymap/blob/main/package.json) и [реализацией выбора следующей ячейки](https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/notebook/browser/controller/executeActions.ts).

**Граница симуляции.** Вкладка читает учебный документ nbformat 4 (Markdown и код) и сохраняет его ячейки, счётчики выполнения, текстовые выводы и метаданные. Учебное ядро обрабатывает списки целых чисел и выражения `sum`, `max`, `min`, `len`. Данные должны быть выполнены до зависимой ячейки. Произвольный код, личные файлы, сторонние ядра, виджеты и графики не запускаются. Сохранённый вывод не создаёт переменную в заново открытом блокноте. Это практикум рабочих действий, не универсальный редактор Jupyter.

**Проверки.** `linux/tests/test_editor_notebooks.py` проходит три занятия на трёх наборах данных с профилями Linux и Windows, проверяет содержимое сохранённых файлов и отказ при неверном числе. Отдельно проверяет ошибку порядка исполнения, ограничение ядра и восстановление редактирования после перезапуска процесса. `linux/tests/test_editor_notebooks_x11.py` выбирает миссию через обычный каталог GTK, отправляет нативные события клавиатуры и сохраняет кадры до и после исправления. Тест профиля Windows в движке не заменяет запуск WPF.
