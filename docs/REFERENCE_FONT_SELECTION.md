# TouchTyping reference font selection

The PNG cannot establish a font family exactly. Cyrillic and mixed labels were cropped tightly, comparing drawn ink widths at closest ink height and similar weight across Roboto (variable distributions and official static Roboto v3.016), Inter, Manrope, Open Sans, Noto Sans, and Liberation Sans. Approximate raster mask overlap (IoU) is measured only after normalizing the candidate ink bounds to the reference; the reported natural-width error is measured before resizing. This reduces sensitivity to minor PNG blur, hinting, spacing and threshold choices, but cannot identify the original font. The sample comes from the app chrome, not the simulated browser web page, whose text can use a different family.

The static Roboto choice fits the UI sample (14 labels, 10 Cyrillic, 1 mixed and 3 Latin) with 2.32% mean / 2.09% median absolute natural-width error, .636 mean raster-mask IoU, and .29px mean absolute ink-height difference. Inter gives 2.79% mean width error and .618 overlap, Manrope 3.19%/.523, Open Sans 3.14%/.644, Noto Sans 3.93%/.621. Close alternatives are possible; aggregate stroke-mask overlap alone does not uniquely identify the family. Roboto reads nearest overall (the hero's hard diagonal-stem and rounded parts also align more closely than Inter/Manrope). At 43px bold its hero is 409×41 against 411×40 in reference. Weight 400 for helper text, 500 for nav accents and secondary controls, 700 for hero/title. Keep terminal/code text monospaced and unaffected by this UI-font selection.

Repeat with `python compare-font.py` in this folder on a system providing Pillow, NumPy and Linux distro fonts listed in the script. `font-comparison.txt` stores measures. Candidate Open Sans/Noto/etc depend on distro, and comparison variable variants used Google Fonts distributions; the recommendation ships untouched static files pinned to the official upstream release independently. The archived static files were checksum verified upstream, audited for full Cyrillic/Russian vowels/consonants and `Ёё` in cmap, and carry no `fvar` table. Source and extracted file hashes are in `fonts/roboto-v3.016/ROBOTO-SOURCE.txt`.
