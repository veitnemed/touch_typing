# Как открываются занятия Live

- Перейдите в Live и нажмите карточку Chrome, VS Code, Терминал, Ubuntu / Windows 10 или «Рабочий день». Если у этой среды есть сохранённое занятие, откроется оно, в той же фазе и с прежними лимитами. Иначе начнётся маршрут из **40 действий без таймера**.
- У основного маршрута несколько поручений. Сначала открывается знакомый тип работы, затем — другое поручение на выбранном уровне. Короткие задания по новой теме дополняют старые навыки, а не становятся всем занятием. Пока не достигнут предел, завершение одного дела не прерывает тренировку. Полоса прогресса при лимите действий показывает ход всего занятия.
- В **«Настроить» → «Последовательная практика»** можно самому выбрать сложность, способ подсказок, количество действий и таймер. Оба ограничения можно использовать вместе или отключить. Когда предел наступает посреди поручения, можно закончить занятие либо выполнить оставшиеся шаги этого поручения. Прогресс не сбрасывается.
- Для точечной тренировки выберите конкретное поручение в «Настроить». У него есть отдельный итог: после его завершения новое поручение не стартует. Запуск другой практики не заменяет сохранённое занятие в том же слоте.

Все прежние упражнения доступны на своих уровнях. В терминале обычное занятие чередует длинные рабочие поручения и короткие практики основных команд. Длинные поручения не сводятся к набору строки: используются настоящие для симуляции история, редактирование команды, поиск по файлам, проверка журналов, права, подготовка копий и передач.

## Полные поручения Терминала

| Уровень | Сценарии, доступные и в последовательной практике, и вручную |
|---|---|
| Основы | Разобраться в незнакомом проекте; подготовить и передать отчёт; сохранить исходники перед работой; найти ошибку в журнале |
| Рабочие приёмы | Собрать отчёт с ограниченным доступом; составить каталог файлов проекта; сопоставить журнал и процессы; проверить содержимое перед копированием |
| Сложный | Подготовить проверенный коммит; зафиксировать состояние рабочей среды; передать результаты разбора сбоя; проверить историю и передать изменения |

Зачёт сочетания зависит от изменившегося состояния и активного места ввода. Например, Ctrl+C без выбранного адреса не засчитывается как копирование адреса. Ошибку можно исправить и повторить действие.


## Зачем показывается знакомое действие

Режим «По ситуации» включён при новом занятии с основной карточки. Когда на конкретном сочетании был промах, следующее выполнение остаётся с подсказкой. После двух других зачтённых действий этот же навык можно встретить в виде рабочей цели без клавиш. После самостоятельного успеха тренажёр ищет этот навык в другом поручении с отличающимся рабочим состоянием: например, вместо адреса документации предложит выделить адрес учебной страницы поиска. Показанная по запросу подсказка не засчитывается как самостоятельное вспоминание. При возобновлении скрытая подсказка не раскрывается сама.

Очередь учитывает и ошибки, и давно не встречавшиеся поручения. Отдельные «По шагам» и «Самостоятельно» оставляют полный выбор. Такая проверка навыка в новом контексте не равна проверке удержания через неделю.
