# Три отдельных упражнения GNOME

Выберите «Ubuntu» → уровень «Практика» → нужное поручение:

- **GNOME: терминал на втором рабочем столе.** Переместите терминал, выполните именно `pwd`, вернитесь в исходный `app.py` и допишите пометку с той же позиции. В этой модели два стола с границами, перемещение окна следует за ним, как у установленной привязки направления GNOME. Каталог и текст проекта учебные.
- **GNOME: два окна VS Code.** В переключателе окон одного приложения видны подписи `app.py` и `README.md`. Обычный переключатель может показать Chrome, но это не зачёт за выбор второго окна VS Code.
- **MateBook: левый Super и переключение RU/EN.** Правый Super, Alt и физическая Z/Я различаются. Открытие обзора проверяет левую клавишу, затем тренажёр проверяет оба направления смены учебной раскладки. Упражнение не меняет настройки ОС.

GTK читает текущие привязки из схемы `org.gnome.desktop.wm.keybindings` без записи, при доступности. Для столов берутся направления влево/вправо, для общего переключателя сначала «Переключить окно», затем «Переключить приложение», для группы — «Переключить окна приложения». Обрабатывается первая поддержанная одиночная привязка; нераспознаваемые, пустые, состоящие только из модификаторов и многошаговые привязки не используются. В таком случае тренажёр показывает учебную привязку по умолчанию; это не обещание совпадения с отключённой настройкой. При возобновлении черновика сохраняется его исходный набор клавиш. Windows использует учебный профиль GNOME, не создаёт и не перемещает реальные рабочие столы Windows.

Первичные источники: [схема горячих клавиш GNOME](https://github.com/GNOME/gsettings-desktop-schemas/blob/master/schemas/org.gnome.desktop.wm.keybindings.gschema.xml.in) и [обработчики Mutter](https://github.com/GNOME/mutter/blob/main/src/core/keybindings.c).
