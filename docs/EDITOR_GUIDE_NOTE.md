# Первый урок VS Code: рабочая заметка из проекта

Путь: **Live → VS Code** с чистым профилем, затем первое базовое поручение «Составить заметку по проекту». Оно по-прежнему занимает 33 зачтённых действия в EN и без остановки передаёт управление уроку с блокнотом. Отдельный выбор того же поручения даёт собственный результат.

Изменился смысл действий:

1. В `storage.py` выберите сигнатуру и строку настройки JSON двумя `Ctrl+L`. Один раз скопируйте этот блок и сразу вложите его в `review-notes.txt`.
2. Найдите в `tasks.py` объявление функции добавления задачи. Дополните тот же документ, а не вытесняйте фрагмент из буфера. Сохраните заметку и закройте её на время сверки точки входа.
3. Переключитесь на уже открытый `app.py`, возьмите строку импорта, восстановите закрытую заметку и сохраните третий фрагмент. В конце исходники не изменены, а в одном TXT находятся все три фрагмента в нужном порядке.

Критерий: неправильный фрагмент не даёт зачёт при правильном `Ctrl+V`. Правильный `Ctrl+1` из Проводника не заканчивает урок с изменённой или неполной заметкой. Старый черновик проходит по своей первоначальной последовательности. Новый восстанавливает буфер, незакрытую работу и уже сохранённую заметку с прежнего места.

`linux/tests/test_editor_guide_note.py` повторяет результат и два перезапуска через общий протокол на двух профилях. Проверки обычного окна GTK и WPF дополнительно сверяют сохранённые байты до перехода к следующему уроку.
