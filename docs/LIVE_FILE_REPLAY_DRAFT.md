# Live: проверка копирования, переноса и корзины после продолжения

Локальный кандидат на базе `5049a6c3dc508c28dd2de4fd30477d0aa40a4622`, не релиз. Относится только к учебным файлам.

- При вставке в ту же папку или после исчезновения исходника движок возвращает обычный ответ «Действие сейчас недоступно». Не меняются содержимое, выделение и состояние буфера. Перенос в другую папку по-прежнему удаляет исходник только после успешной вставки; копирование сохраняет оба файла.
- Имена объектов в учебной корзине выдаются в фиксированном порядке, с пропуском занятых имён. Журнал действий после обычного завершения восстанавливает те же пути в корзине и их содержимое.
- Протокольная проверка дважды запускает отдельный процесс с одним тестовым профилем: проверяет буфер после незавершённого переноса, путь и содержимое в корзине, выделение, фокус и восстановление по Ctrl+Z. Сравнение игнорирует только временные идентификаторы вкладок; счёт новой попытки, как и прежде, начинается с нуля.

Формат профиля не менялся. Старый журнал восстанавливает тот же учебный файл, но не прежний случайный внутренний путь корзины: этот путь в журнале не сохранялся. Полная миграция профиля с v1.7.0, восстановление после аварийного выхода и ввод в нативном окне Windows в этот срез не входят.
