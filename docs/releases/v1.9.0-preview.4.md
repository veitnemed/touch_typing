### Ноутбуки и файлы в Live → VS Code

- Прочитайте задачу в `.py`, откройте `.ipynb`, измените ячейку, выполните расчёт и перенесите проверенный ответ в файл проекта. Видно, откуда взялся результат: он сохранён в файле, получен в текущем запуске или остался от прежних данных. Используйте `Ctrl+Enter` для запуска текущей ячейки и `Shift+Enter` для запуска с переходом.
- В Explorer внутри VS Code переименуйте CSV через `F2`, перенесите его в `reports` через `Ctrl+X` и `Ctrl+V`, откройте по новому пути, допишите строку и сохраните. При совпадении имён чужой файл не заменяется; `Esc` отменяет переименование. Загрузка из Chrome и передача скачанного файла в проект остались в каталоге.
- Всё происходит в учебном проекте. Устанавливать Jupyter не нужно.

**Запуск.** Ubuntu x64: распакуйте `.tar.gz` и выполните `bash install.sh` из распакованной папки. Windows x64: распакуйте весь ZIP в одну папку и запустите `TouchTyping.exe`.

Обе сборки проверены из архивов: GTK/X11 на Ubuntu и WPF на Windows Server. Windows 10/11 на физическом ноутбуке и Wayland в этом прогоне не проверялись.
