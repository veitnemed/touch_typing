### Приёмка обычных маршрутов и сохранённого состояния

Первое поручение VS Code сохраняет прежние навыки и занимает 33 действия, но теперь три извлечённых фрагмента действительно попадают в одну заметку для ревью. Из неё можно вернуться к исходнику; прежний черновик открывается по тому же сценарию, на котором был сохранён. Блокнот остаётся отдельным содержательным поручением внутри общего курса, а не заменяет редактор и другие темы.

В самостоятельном CSV-поручении можно осмотреть соседнюю папку и прийти к цели стрелкой вверх или вниз. Зачитывается выбор нужного пути, а не лишние детали раскрытия дерева. Для задания на конкретную комбинацию проверка нажатия остаётся строгой; файлы при конфликте не затираются.

Проверки выпуска повторяют запуск обоих распакованных архивов, переход за границу первого поручения, возврат к сохранённому состоянию и поведение при неверном сочетании или фокусе. Распакованный Windows EXE дополнительно запускается без тестовых параметров в новом профиле Live на Windows Server. Для Linux отдельно проверяются штатный запуск GTK/X11 и две карты физических клавиш. Сравнение с настоящим VS Code/Jupyter использует один и тот же файл и результат, а не статический макет.

В GTK рамка каталога показывает карточку с реальным клавиатурным фокусом. После выхода из VS Code первая карточка больше не остаётся обведённой вместо той, на которую вернулся пользователь. В окне паузы Tab и Shift+Tab остаются внутри трёх доступных действий.

Растровый тест WPF при 96/120/144 DPI проверяет сам рендер, а не настройки масштаба клиентской Windows. Физический MateBook, клиентская Windows 10/11 и Wayland не проверялись.

**Запуск.** Ubuntu x64: распакуйте архив, запустите `bash install.sh`. Windows x64: распакуйте весь ZIP и запустите `TouchTyping.exe`.
