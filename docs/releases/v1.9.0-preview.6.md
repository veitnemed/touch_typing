### Live: обычный курс, выбранное поручение и черновик

На основной карточке Live начинается занятие, а не одно выбранное за ученика короткое поручение. Если для выбранной среды и профиля есть совместимое сохранение, можно сразу продолжить. В «Настроить» остаются последовательная практика, отдельные задания и ограничения по времени и действиям.

В стандартном занятии после одного поручения начинается другое. В VS Code ноутбуки встречаются в общем курсе наряду с редактированием Python и работой с файлами. В Терминале короткие команды не вытесняют полноценные задания с файлами, журналами, архивами и Git.

Также доступны новые виды практики в «Печати»: цифры, знаки верхнего ряда, горячие клавиши и смешанный набор. Сочетания распознаются по физическим клавишам, текст — по введённым символам. Карточка показывает точность и время одной и той же завершённой попытки.

**Запуск.** Ubuntu x64: распакуйте архив, выполните `bash install.sh` из распакованной папки. Windows x64: распакуйте весь ZIP, запустите `TouchTyping.exe`.

Проверки окон GTK/X11 и WPF выполняются на стендах Ubuntu и Windows Server. Это не проверка Wayland, клиентской Windows 10/11 или физической клавиатуры MateBook.
