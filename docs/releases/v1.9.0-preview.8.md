### Работа над ошибками по конкретной попытке

При точности ниже 98% на результате основного занятия появляется «Работа над ошибками». Из промахов всех циклов этой попытки собирается персональная смесь из 150–200 символов и действий. Частые ошибки встречаются в ней чаще. Сочетания снова выполняются физически, а не печатаются как названия.

Незавершённое исправление можно продолжить после перезапуска. Исходная попытка допускает только одно завершённое исправление; у результата исправления нет кнопки для следующего исправления. При ровно 98% кнопка не появляется.

В «Печати» обе сборки используют один каталог прежних и новых занятий. По умолчанию один конечный цикл без таймера; если выбрано несколько циклов, счётчик общий, а в бесконечном режиме полосы нет. Цвет карточки определяется неокруглённой точностью лучшей завершённой попытки; время относится к ней же. Руки и клавиатура на новом профиле включаются по желанию.

В истории можно снова открыть **итог** уже завершённой работы над ошибками, но пройти её заново нельзя. В профиле MateBook сочетание Alt+Home может указывать на 7/Home цифрового блока; верхняя клавиша 7 не заменяет Home. Подписи Ctrl+V и Ctrl+B сохраняют латиницу, а в русской раскладке подсвечиваются физические М и И.

**Запуск.** Ubuntu x64: распакуйте архив, выполните `bash install.sh` из распакованной папки. Windows x64: распакуйте весь ZIP, запустите `TouchTyping.exe`.

Проверки относятся к GTK/X11 на Ubuntu и WPF на Windows Server. Физический MateBook и клиентская Windows 10/11 не проверялись.
