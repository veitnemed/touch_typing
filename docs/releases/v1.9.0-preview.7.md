### Live: работа с реальным состоянием учебного проекта

Старый курс остаётся на основных карточках. На уровне «Рабочие приёмы» новые поручения дополняют его: в Chrome можно сверить версии бюллетеня и открыть нужный CSV; в «Рабочем дне» перенести отчёт в папку проекта и сохранить заметку с источником и строкой из этого файла. В симуляциях Ubuntu и Windows 10 используются свои действия для окон, переключения и файлов. На сложном уровне отдельная задача начинается с ошибки в журнале и заканчивается проверкой правки.

В VS Code блокнот остаётся частью курса рядом с Python, CSV и проводником. У ячеек есть режимы выбора и редактирования, отдельный запуск и результат под кодом. Расчёт может читать учебные CSV и импортировать соседние модули, а перезапуск очищает состояние ядра. В трёх новых поручениях можно починить структуру блокнота, устранить сбой после запуска с чистого ядра и проследить CSV от перемещения в Explorer до проверенного расчёта. Код исполняется учебной моделью: поддерживается ограниченный набор Python, без доступа к файлам пользователя и без установленного Jupyter.

Если после перехода к определению блокнот перенесли, «Назад» возвращает к той же ячейке по новому пути. При предельном размере блокнота очередное увеличение отклоняется до записи: ранее сохранённый файл остаётся доступен.

В последовательной практике сложный для ученика приём возвращается сначала с подсказкой, затем без ответа и в другой рабочей ситуации. Остальные темы продолжают встречаться, а явный выбор режима без подсказок не меняется.

Исправлено определение физических клавиш на X11: обычные стрелки и цифровой блок различаются и на картах XFree86, и на evdev. Если системное сочетание забирает диспетчер окон, тренажёр не засчитывает неполученное действие.

**Запуск.** Ubuntu x64: распакуйте архив, выполните `bash install.sh` из распакованной папки. Windows x64: распакуйте весь ZIP, запустите `TouchTyping.exe`.

Проверки относятся к GTK/X11 на Ubuntu и WPF на Windows Server. Профиль Windows 10 внутри симуляции не заменяет проверку на клиентской Windows; физический MateBook в этот выпуск не входит.

У каждого из трёх связанных поручений VS Code есть свой итог. На месте проверяющего результата недостаточно просто открыть экран с нужным именем: проверяются использованный файл, выполненное действие и сохранённый результат.

**Ограничение preview.** В сложном CSV-поручении, открытом без подсказок, подход к нужной папке другим путём (например, стрелкой вверх после осмотра соседней папки) может не засчитаться. Основной маршрут проверен в режиме «По шагам». При совпадении имён файлы не перезаписываются.
