### Конечная и бесконечная печать

В «Печати» можно сразу начать обычное занятие: один цикл на 350–550 символов, без таймера. Последний правильный символ завершает занятие. Несколько циклов выбираются в компактных параметрах: общий счётчик и полоса не обнуляются между ними. Например, переход выглядит как `399/900 → 400/900 → 401/900`. Ошибка не продвигает каретку.

По кнопке «Продолжить» открывается то же сохранённое конечное занятие, с его текстом и позицией. Бесконечную печать нужно включить явно: там остаётся счётчик набранного, но нет полосы, процента или пустой строки для них.

**Запуск.** Ubuntu x64: распакуйте архив, в его папке выполните `bash install.sh`. Windows x64: распакуйте весь ZIP, запустите `TouchTyping.exe`.

Проверки открытого окна выполнены в GTK/X11 на Ubuntu и в WPF на Windows Server; это не прогон на физическом MateBook или Windows 10/11.
