# «Печать»: как считается прогресс

Обычное занятие — один цикл из 350–550 символов без таймера. Последнее правильное нажатие завершает занятие автоматически; ещё раз нажимать Enter не нужно. Если до старта выбрать несколько циклов, тренажёр заранее подберёт материал каждого из них.

У всей попытки один счётчик. Для циклов по 400 и 500 символов переход выглядит так: **399/900 → 400/900 → 401/900**. Ошибка увеличивает число промахов, но не приближает конец. Пауза останавливает активное время. При штатном выходе сохраняется весь конечный план, позиция и ошибки; **«Продолжить»** после запуска восстанавливает ту же попытку, а не заново подбирает следующий текст. Явный выход с завершением показывает результат и не оставляет черновик этой попытки.

**Бесконечная печать** включается отдельно. У неё есть счётчик набранного, но нет общего количества символов, процента и полосы прогресса. Добровольный таймер ограничивает время, а не изменяет длину конечного плана: если время вышло раньше, это не полное прохождение запланированного текста.

Для воспроизведения на чистом профиле запустите тест обеих оболочек на уровне их общего протокола:

```sh
dotnet build linux/engine
PYTHONPATH=linux:linux/tests python3 -m unittest test_classic_cycles
```

Этот тест вводит каждый символ текущего фрагмента, проходит границу 400/900, дважды перезапускает процесс и проверяет одну запись результата. Он не заменяет проверку GTK/WPF в открытом окне.
