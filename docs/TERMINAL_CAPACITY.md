# Live: «Не сохранился архив: проверить место»

Это дополнительное поручение, не замена тренировке по журналам. Путь: **Live → Ubuntu / Windows 10 → Терминал / PowerShell → Настроить → Не сохранился архив: проверить место → Начать**. Уровень «Основы».

1. В учебной заявке видны путь назначения и размер архива. После проверки правильного диска в Bash прочитайте `Avail` из `df -h <путь>`; в PowerShell прочитайте `Free (GB)` из `Get-PSDrive <буква>`. Если проверяли системный диск вместо указанного, шаг не засчитывается. В Bash работает и `df -h .`, если сначала перейти в нужную папку.
2. Сравните свободное место с размером архива и нажмите `1` (не хватает) или `2` (хватает). В результате видны обе величины и вывод: если места достаточно, причину нужно искать дальше; если его мало, это не повод сразу удалять файлы.

Варианты меняют путь, букву диска, имя файла и объём. Команды работают на изолированных учебных томах и не изменяют ни файлы, ни диск компьютера. Незавершённое поручение можно продолжить: восстанавливаются вывод терминала и вопрос, на котором остановился ученик. Обычный вход с карточки по-прежнему открывает разбор ошибки в журнале.

Для проверки: `python3 linux/tests/test_terminal_disk_space.py` с собранным движком. Проверка настоящего GTK-окна: `linux/tests/test_terminal_disk_space_x11.py` по правилам квалификации, значения `TOUCH_TYPING_QA_SEED=1` и `5` дают разные выводы. Windows-обозреватель находится в `windows/Test-LiveCourseCards.ps1`.

С Preview 14 там же доступно отдельное упражнение **«Проверить место без подсказки»**. Заявка, архив и путь не меняются, но свободного места может хватать или не хватать. Ответ нужно получить из вывода по целевому диску. Теория закрыта при входе; её можно открыть самому. Исходный урок и его сохранённые занятия не меняются.
