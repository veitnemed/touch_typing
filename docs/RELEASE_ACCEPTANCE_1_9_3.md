# Приёмка TouchTyping 1.9.3

Точка отсчёта: опубликованный v1.9.2. Новые задания дополняют существующий курс. Ни прохождение движка, ни количество записей в каталоге не заменяют прохождение обычного маршрута в окне приложения.

| Область | Что нужно подтвердить | Доказательство |
| --- | --- | --- |
| Запуск | Из обычного меню начать и продолжить «Печать» и Live, вернуться назад и снова начать. Для завершившегося и зависшего движка сохранить уже записанный черновик. При невозможности запуска показать ошибку, не переотправлять действие без явного повторного запуска. | Linux: тест живого, но не отвечающего процесса. Оконные испытания Linux и Windows: отдельно. ## Локальные результаты составных проверок

- Движок прошёл 30 сочетаний «раздел, профиль ОС, уровень» через обычный маршрут при seed 0. На базовом уровне использован штатный лимит 40, на двух остальных для проверки переходов выставлен лимит 100. У каждого зачтено минимум 30 действий; терминальные карточки обеих систем не закрывают занятие после первого поручения.
- В GTK/X11 на чистых профилях проверены обычные карточки, 30 действий терминала в каждом учебном профиле, 46 действий нового поручения VS Code с Git, история Chrome и возврат в Проводник. Профиль Windows внутри GTK не заменяет запуск WPF.
- Для TXT скачан публичный Linux-архив 1.9.2, проверен SHA-256. Черновик, сохранённый им посреди команды, открыт в новом движке с прежней кареткой; новый старт задаёт корректное перенаправление. Это проверено в обоих учебных профилях. Успешный старый TXT не должен оставаться после нового неудачного теста.
- В реальном Bash повторена проверка обоих потоков, а для обновления копии проверены план без записи, две изменившиеся записи, сохранение старого файла и ноль изменений при повторе. Частота использования команд не измерялась.
