# Сценарии Live: рабочая задача, а не список клавиш

Пример с переносом ссылки из Chrome в VS Code остался отдельным упражнением.
Он не заменяет исходные маршруты и не запускается первым на чистом профиле.
В ограниченной по времени тренировке новые маршруты перемешиваются со старыми;
законченный короткий эпизод не завершает такую тренировку досрочно. В каталоге
по-прежнему можно выбрать конкретный эпизод и продолжить сохранённый.

| Повседневная задача | Результат, который проверяет тренажёр |
| --- | --- |
| Найти справку по Python | В буфере ссылка на конкретный раздел, а не на главную или обзор |
| Скачать и проверить рабочий отчёт | Открыт именно скачанный CSV, найдена заданная запись |
| Сравнить выпуски инструмента | Открыт предыдущий выпуск, затем из закладок заново открыт актуальный |
| Восстановить закрытый источник | Нужная инструкция открыта из истории, ссылка готова к передаче |
| Перенести отчёт в проект (Ubuntu / Windows 10) | Файл открыт уже в проекте, исходник убран из «Загрузок», в файле найдена указанная запись |

У каждого семейства три набора материалов: меняются тексты, адреса, названия
файлов и фактические ответы. Позиция подходящего результата в выдаче меняется.
Некорректный запрос не подставляет ответ, а неверный идентификатор записи не
засчитывается. Состояние вкладок, файлов, истории и буфера проверяется в
симуляции. Материалы написаны для тренажёра и работают без сети.

Первоисточники для учебных заметок: [json.dumps](https://docs.python.org/3/library/json.html#json.dumps),
[Path.read_text](https://docs.python.org/3/library/pathlib.html#pathlib.Path.read_text) и
[csv.DictReader](https://docs.python.org/3/library/csv.html#csv.DictReader).

## Приёмка

- LabRegression: пройти 12 вариантов Chrome, проверить итоговые адреса,
  содержимое файла, отрицательные примеры, смешанный цикл и оба профиля «Рабочего дня».
- GTK: XTest/GDK с реальным удержанием Backspace, переход из каталога,
  поиск и сохранение; открыть скачанный архив в чистой папке, без пользовательского профиля.
- WPF: извлечённый ZIP на Windows Server, ввод по SendInput, отдельные
  свидетельства по поиску, Проводнику и перемещению файла. Проверка Windows
  Server не является аппаратным тестом или запуском на клиентской Windows 10.
